Bách khoa toàn thư Động vật

Nekopara là một nền tảng Web Application được phát triển hoàn toàn bằng PHP thuần. Kết hợp giao diện người dùng Shadcn UI (Nature Theme) tinh tế, hệ thống cho phép người dùng tra cứu, học hỏi và tương tác chia sẻ kiến thức về thế giới động vật muôn màu.

PHP 8.1+ & MVC

Lõi hệ thống được thiết kế theo chuẩn MVC, phân tách logic rõ ràng, dễ bảo trì, tích hợp cơ chế Autoloading hiện đại.

Tailwind & Bootstrap

Trải nghiệm UI/UX tối ưu hoá với Glassmorphism, Micro-animations và hệ thống màu sắc HSL tuỳ chỉnh.

Bảo mật Tối đa

Mã hoá mật khẩu Bcrypt, chặn truy cập trái phép bằng Middleware Auth, bảo vệ lỗ hổng SQL Injection bằng PDO Prepare.

Đa Ngôn Ngữ (i18n)

Tích hợp sẵn thư viện dịch thuật (EN/VI) với hàm __('key') cho toàn bộ các text cứng trên giao diện Admin và Client.

Cấu trúc

Kiến trúc MVC

Mọi request được điều hướng và xử lý theo mô hình phân lớp chuyên nghiệp.

animal_php_myadmin/ ├── config/ # Cấu hình (.env, lang) ├── controller/ # Logic xử lý (BaseController, UserController...) ├── database/ # Chứa tệp SQL import_data.sql ├── images/ # Tệp tĩnh và Upload người dùng (bảo vệ bởi .gitignore) ├── lib/ # Thư viện core (i18n.php) ├── model/ # Lớp tương tác CSDL (Entities) ├── view/ # Giao diện HTML/PHP │ ├── admin/ # Giao diện Quản trị │ └── client/ # Giao diện Người dùng ├── autoload.php # Trình nạp Class tự động └── index.php # Điểm neo điều hướng

Cơ chế Autoloading

Dự án sử dụng spl_autoload_register. Bạn không cần phải gọi require_once cho các class Model và Controller nữa. Hệ thống sẽ tự động nạp file khi khởi tạo đối tượng `new ClassName()`.

Khởi chạy

Cài đặt Môi trường

Chỉ mất 2 phút để đưa dự án lên môi trường Localhost.

1

Clone hoặc Tải mã nguồn

Giải nén dự án vào thư mục gốc của Web Server.

  • Laragon: C:\laragon\www\animal_php_myadmin\
  • XAMPP: C:\xampp\htdocs\animal_php_myadmin\
2

Cấu hình `.env` tự động

File config/env.php đã được lập trình để tự động dò tìm Domain và Folder Path. Bạn không cần cấu hình thủ công biến BASE_URL, hệ thống sẽ tự sinh link tuyệt đối cho CSS/JS.

3

Truy cập Trình duyệt

Mở trình duyệt và truy cập vào đường dẫn sau:

http://localhost/animal_php_myadmin/animal_php_myadmin/
Database

Nhập Dữ Liệu SQL

Hệ thống sử dụng PDO MySQL. Bạn cần tạo Database và import dữ liệu mẫu để chạy ứng dụng.

1

Mở phpMyAdmin (thường là http://localhost/phpmyadmin).

2

Tạo mới cơ sở dữ liệu có tên chính xác là: animal_db (Collation: utf8mb4_unicode_ci).

3

Chọn DB vừa tạo, bấm qua tab Import.

4

Tải lên tệp SQL có sẵn trong mã nguồn:

database/import_data.sql
5

Bấm Go (Thực hiện) để hệ thống tự tạo bảng và đổ dữ liệu.
