Refactor Hệ màu CSS Design Tokens

Tích hợp Design Tokens hệ màu Shadcn & Tách file CSS

Refactor toàn bộ bảng màu gốc, xây dựng hệ biến HSL trung tính (Zinc/Slate) cùng chế độ tối, bóc tách CSS Inline ra các tệp tin độc lập.

Chức năng & Tối ưu:

  • Hệ màu Shadcn HSL: Tích hợp thiết kế hệ biến màu HSL (`--primary`, `--background`, `--card`, `--border`, `--ring`) giúp dễ dàng chuyển chế độ sáng/tối tự động và giữ được sự sang trọng, đồng bộ.
  • Bóc tách CSS Inline: Di chuyển toàn bộ các đoạn mã thẻ `<style>` inline bên trong 15 file PHP sang các file CSS độc lập giúp cache trình duyệt tốt hơn, dọn dẹp sạch sẽ mã nguồn PHP.
  • Hộp nhập liệu & Nút tinh tế: Tạo các class input (`.shadcn-input`) với focus-ring mảnh và card bóng đổ mịn (`.shadcn-card`) thay thế cho thiết kế thô cũ.

Hệ thống Autoloading nguyên bản & Quản lý biến môi trường .env

Triển khai cơ chế import tự động cho toàn bộ Model và Controller, cấu hình .env linh động tránh lỗi đường dẫn 404.

Chức năng & Tối ưu:

  • Quản lý cấu hình .env: Cung cấp file `.env` chứa `BASE_URL` động giúp toàn bộ đường dẫn tài nguyên (CSS, JS, Image) tự động nhận dạng chính xác trên bất kỳ môi trường chạy nào (Laragon, XAMPP, Staging, Live).
  • Autoloading nguyên bản: Sử dụng `spl_autoload_register` đăng ký cơ chế load Class động. Dọn dẹp hơn 50 câu lệnh `require_once` thừa thãi trên các tệp tin View, tránh rác mã nguồn.
